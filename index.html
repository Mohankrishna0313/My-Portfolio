Autonomous Indoor Navigation Robot for Restaurant Environments

A robot that serves food on restaurant floors on its own, using computer vision to spot obstacles and route around them while it moves.

System overview
Cameralive frames
YOLOv5 + OpenCVobstacle detection
Raspberry Pivision + decisions
Google Maps APIroute planning
Arduino Unomotor + sensor control

The problem

Serving food on a restaurant floor is repetitive manual work, and the floor is full of moving people and obstacles. The robot automates the task and has to avoid obstacles without human help.

My contribution

Engineered the full hardware-software system: a Raspberry Pi as the vision and decision unit, and an Arduino Uno for low-level motor and sensor control.

Key features

  • Real-time obstacle detection by running YOLOv5 with OpenCV on live camera frames.
  • Autonomous path planning that combines detection output with the Google Maps API, so the robot can compute routes and re-route around obstacles without manual intervention.
  • Faster delivery: simulated food-delivery time dropped 40% against a manual baseline in controlled testing.
  • Peer-reviewed: published in IEEE Xplore (Jul 2025) and presented at ICCRTE 2025.

Anomaly Detection in Wearable Health Devices

A real-time pipeline that watches wearable sensor readings, flags abnormal heart rate and SpO2 values as they arrive, and alerts someone straight away.

Data pipeline
Wearable sensorheart rate, SpO2
Pandasprocess incoming data
Anomaly checkflag abnormal values
Email alertwithin 2 seconds
Flask dashboardlive monitoring

The problem

Critical readings are easy to miss when someone has to keep checking vitals by hand. This system escalates them automatically.

My contribution

Built the full pipeline: data processing and anomaly flagging, the automated alerting, and the web dashboard with its HTML, CSS and JavaScript front end.

Key features

  • Real-time detection of abnormal heart rate and SpO2 values, processed with Pandas as readings arrive.
  • Automated email alerts triggered within 2 seconds of an anomaly being detected.
  • Live Flask dashboard for health-metric monitoring.
  • Less manual effort: monitoring effort fell 70% in simulated trials.
